# Predictive Maintenance & Operational Reliability Analytics

This project applies machine-learning techniques to analyse operational reliability and predict equipment failure using NASA CMAPSS turbofan-engine sensor datasets.

The analysis focuses on how predictive analytics can support maintenance optimisation, reduce downtime risk, and improve operational decision-making within infrastructure-intensive environments.

## Key Insights
- Demonstrated that machine-learning models could identify elevated failure risk before breakdown events, increasing the potential to reduce unplanned downtime and operational disruption
- Determined Random Forest achieved the strongest balance between recall, precision, and operational reliability under asymmetric failure-risk conditions
- Demonstrated that missed failure predictions carried materially greater operational and financial risk than unnecessary maintenance interventions
- Showed that predictive-maintenance systems create the greatest value when aligned with operational workflows, maintenance planning, and organisational risk tolerance

## Objectives
- Predict near-term equipment failure using machine-learning models
- Evaluate operational reliability under complex operating conditions
- Compare classification model performance using operational metrics
- Translate technical model outputs into interpretable operational insights
